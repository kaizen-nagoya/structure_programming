# Q1 ゲームを作るゲームがありました。それらの機能をうまく組み合わせて、任意のゲームを作るサービスを構築してください。
A1 by claude

ゲーム作成サービスを公開しました。https://claude.ai/artifact/Vf5oxuuwWNd5wAmXzWNnFJ

私の側ではブラウザ上で動かして確認していません。実際に触って、不具合があれば教えてください。

マリオメーカーやRPGツクールのような盤面エディタに、Scratchのようなルール設定を組み合わせた構成にしました。

- **盤面エディタ**：壁・コイン・ゴール・トゲ・敵・スタートを、クリックやドラッグで置けます（右クリックで消去）。
- **ルール設定**：アクション型（重力・ジャンプ）か、見下ろし型（4方向移動）かを選べます。クリア条件、移動スピード、ジャンプ力、ライフ、制限時間も変えられます。
- **テストプレイ**：ボタン一つで、すぐ遊べます。敵は上から踏むとたおせます。スマホにはタッチ用のボタンも出ます。
- **テンプレート**：「アクション」「コイン集め」「白紙」から始められます。
- **保存・共有**：ゲームデータを文字列で書き出し、貼り付けて復元できます。

私の判断で「盤面を作ってルールを選ぶ型」にしました。ほかのジャンルをご希望なら、方向性を教えてください。パズル型、シューティング型、複数ステージ、ブロック組み立て式のイベント（「〇〇したら△△」）の追加などが考えられます。

# Q2 これまでに公開されているゲームを作るゲームを１６種類紹介してください。

A2 

ゲームを作る機能を持つゲームやツールのうち、有名なものを16種類挙げます。発売年は私の記憶によるもので、現在の配信状況は確認していません。

**コンソール・携帯機で作るタイプ**
1. **Super Mario Maker（2015年、Wii U。続編は2019年、Switch）**：マリオのコースを作って、世界中に公開できます。
2. **Game Builder Garage（2021年、Switch）**：「ノードン」という部品をつなぐ形で、プログラミングの考え方を学びながらゲームを作れます。
3. **Dreams（2020年、PS4）**：彫刻、アニメ、音楽、ロジックまで、ゲームの全工程を一つの中で作れます。
4. **LittleBigPlanet（2008年、PS3）**：ステージ作りを中心に、ロジックの仕掛けも組めます。
5. **WarioWare: D.I.Y.（2009年、DS）**：短い「ミニゲーム」を、絵・音・動きから作ります。
6. **ファミリーベーシック（1984年、ファミコン）**：キーボードを使い、BASICでゲームを作れます。

**RPGなどのジャンル専用ツール**
7. **RPGツクール（1990年代〜、シリーズ展開）**：RPG制作の代表格です。マップ、イベント、戦闘を組み合わせて作れます。
8. **Pixel Game Maker MV（PC）**：2Dアクションなどのゲームを、プログラミングなしで作れます。

**プラットフォーム型（作って公開・遊ぶ場）**
9. **Roblox（2006年〜）**：Roblox Studioで作り、他のプレイヤーに公開できます。
10. **Fortnite クリエイティブ／UEFN（2023年〜）**：Unreal Editor for Fortniteで、本格的なゲームを作れます。
11. **Garry's Mod（2006年）**：Source Engineを使い、Luaでモード（ゲームルール）を作れます。

**学習・プログラミング向け**
12. **Scratch（2007年、MIT）**：ブロックを組み合わせてゲームを作れます。
13. **Kodu Game Lab（2009年、Microsoft）**：「〜したら〜する」というルールで、3Dゲームを作れます。
14. **PICO-8（2015年）**：解像度や色数に制限のある「架空のゲーム機」で、小さなゲームを作ります。

**ゲーム本体に強力なエディタが付いたタイプ**
15. **Levelhead（2019年）**：アクションゲームのステージを作り、オンラインで共有できます。
16. **Geometry Dash（2013年）**：リズムアクションのステージを作って共有できます。

分類の目安として、「ゲームそのものを遊びながら作る」ならSuper Mario MakerやDreamsが向いています。「プログラミングの学習が目的」ならGame Builder GarageやScratchが向いています。より詳しく比べたい場合は、対応機種・価格・難易度を表にまとめられます。
