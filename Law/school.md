# Q1 職業訓練校に関する法体系を示してください。
A2 by Claude

職業訓練校は法律上の正式名称ではなく、通称です。根拠となる中心の法律は職業能力開発促進法で、施設の正式名称は「職業能力開発校」です。県によっては「高等技術専門校」などの名称を使っています。以下は検索結果と私の知識をもとに整理したものです。個別の判断には、必ず現行の条文をご確認ください。

## 1. 全体の体系（上位から下位へ）

```
日本国憲法（第25条 生存権、第27条 勤労の権利）
 └ 職業能力開発促進法（昭和44年法律第64号）【中心となる法律】
     ├ 施行令（政令）
     ├ 施行規則（厚生労働省令）…訓練の課程・基準・訓練時間・指導員など
     ├ 告示・通達…訓練基準の詳細、運用
     └ 都道府県の職業能力開発促進法施行条例・設置条例
         …各校の設置や運営の具体策
```

## 2. 中心となる法律：職業能力開発促進法

- **施設の種類**
  公共職業能力開発施設は、職業能力開発校、職業能力開発短期大学校、職業能力開発大学校、職業能力開発促進センター、障害者職業能力開発校に分けられます。
- **職業能力開発校の定義**
  普通職業訓練で、長期間および短期間の訓練課程のものを行う施設です。
- **設置主体**
  職業能力開発校は都道府県が設置し、令和6年4月現在で145校あります。市町村の設置も1校あります。
  国が設置する障害者職業能力開発校は、独立行政法人高齢・障害・求職者雇用支援機構や都道府県が運営します。
- **訓練の種類**
  普通職業訓練と高度職業訓練に分かれます。各課程（普通課程・短期課程・専門課程・応用課程）は、省令で定められています。
- **このほか同法が定めること**：職業訓練指導員の免許、認定職業訓練（事業主などが行う訓練の認定）、技能検定、職業能力開発計画などがあります。

## 3. 地方の定め（条例）

- 職業能力開発促進法施行条例が、各都道府県で定められています。例えば公共職業能力開発施設以外の施設で行える職業訓練は、知識習得が中心で、短期課程の普通職業訓練に準じるものなどと定められています。
- 校の設置や名称、授業料などは、各都道府県の条例で定まります。

## 4. 関連する主な法律

| 分野 | 法律 | ポイント |
|---|---|---|
| 運営・財政 | 独立行政法人高齢・障害・求職者雇用支援機構法 | 機構が大学校や促進センターを運営 |
| 求職者支援 | 職業安定法、雇用保険法 | 公共職業訓練の受講指示・推薦、受講中の給付 |
| | 職業訓練の実施等による特定求職者の就職の支援に関する法律（求職者支援法） | 雇用保険を受けられない人向けの訓練と給付金 |
| 障害のある人 | 障害者の雇用の促進等に関する法律 | 障害者職業能力開発校の根拠の一つ |
| 雇用施策 | 労働施策総合推進法 | 職業能力開発を含む国の施策の方針 |
| 労働関係 | 労働基準法 | 戦後の企業内技能者養成の出発点 |
| 学校制度 | 学校教育法 | 専修学校（専門学校）など。職業訓練校とは別の制度 |

## 5. 沿革（短く）

制度の出発点は昭和22年の二つの制度です。企業内の技能者養成（労働基準法）と、失業対策としての公共機関による職業補導（職業安定法）が、発足の2本の柱でした。その後、職業訓練法を経て、現在の職業能力開発促進法に至っています。

## 6. 入校の仕組み

普通課程は高校卒業程度の学力が必要で、入校試験があります。短期課程は、ハローワークで求職申込みをして受講指示または推薦を受けた人が対象です。手続きの詳細は、ハローワークや各校に確認する必要があります。
